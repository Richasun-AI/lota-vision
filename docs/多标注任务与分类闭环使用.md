# 多标注任务与分类闭环使用

## 标注任务

在“标注系统”点击“管理标注任务”。为每套任务填写代码、名称、类型和标签，按需绑定独立的 Label Studio 项目。通信巡检预建照片类型分类、设备检测、围墙铁丝网缺陷检测和地面状态分类任务。

标注、数据集和模型页面上方的任务选择器决定当前操作范围。工作流节点的 annotation_task 参数绑定同一任务代码。任务输出保存在场景的 annotation-tasks/任务代码目录，原图从场景 raw 共享读取。

检测必须画全当前任务标签表中的目标，并选 Targets reviewed；无目标必须选 No target。不确定选 Unsure。整图分类只允许一个 category，并选 Category reviewed。任务新增或改变标签后，原有标注需要按新标签表复核。发布会检查原始确认记录和标签表版本，排除未确认或版本不符的数据。

原有场景顶层设置保留为历史默认任务，已有数据继续可见。新标注使用独立任务。

## 照片类型学习闭环

1. 在原图与分拣选择一组图片，点击“确认所选图片类别”，选择当前场景启用的照片类型。人工类别立即写入复核图库，并保留修改记录。
2. 确保训练样本有可信的站点 ID。同站图片一起进入训练或验证，训练与验证的每个类别都需要有独立站点样本。
3. 点击“训练照片分类器”，填写新的版本代码。服务器已配置本地 SigLIP 特征模型，可以留空 model_dir 使用配置。引擎提取并缓存图片特征，训练逻辑回归，返回独立站点验证结果。
4. 点击“重新归类所选图片”，指定版本及置信度阈值。低置信度进入待确认，人工纠正优先于模型。
5. 重新归类成功后，该版本成为当前场景自动分拣使用的分类器。后续“运行自动分拣”优先使用它，历史预测文件只作为尚未启用自身分类器时的候选来源。

特征以图片内容哈希和模型指纹缓存，批量提取自动使用可用 GPU。新建类别后要补充该类别人工样本，再训练新版本。分类建议本身不会成为人工标签。

## 验证范围

已覆盖多任务标注隔离、空标签确认、单标签分类、标签表变更复核、按站点训练和人工纠正保留。真实图片验证了 768 维特征提取；完整训练与重新归类使用独立合成样本验证。合成样本结果不代表巡检业务准确率，业务效果须使用真实人工标签与留出站点评估。
