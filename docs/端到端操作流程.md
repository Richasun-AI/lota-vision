# 端到端操作流程：从照片到多类别模型

这份指南按实际操作顺序写：先把照片收进子项目，再标注、打包、训练；模型要识别新东西时，按“加类别”的流程走。每一步都写了在哪个页面点什么、做完应该看到什么，以及容易踩的坑。

一个子项目对应**一个模型**，这个模型可以识别**多个类别**，以后还能接着加。例如一个子项目先只有 `crack`（裂缝），后来加上 `rust`（锈蚀），训练出来的是同一个同时认这两样的模型。

---

## 0. 开始之前：确认当前子项目

所有页面（工作台、工作流、数据集、模型中心）共用顶部选的“当前子项目”。**每次操作前先看一眼顶部选的是不是你要的子项目**。打包、训练、抽图都只作用于当前子项目，选错了就会把图抽进别的子项目、打包时报“没有已复核的标注”。

---

## 1. 把照片收进子项目

照片有三个来源，按需选一个。

| 来源 | 在哪操作 | 适合 |
|---|---|---|
| **照片类型页已归好类的照片** | 工作台 →“原图与分拣”→「从照片类型抽图」，或工作流模板「从照片类型抽已确认的图」 | 要某一类照片（如某一类设备照片）；类别会一起带过来，不用重新分拣 |
| 子项目配置的原图目录 | 工作台 →“原图与分拣”→「扫描原图」 | 有固定的原图来源目录 |
| 服务器上的一个文件夹 | 工作流节点「导入图片文件夹」 | 临时的一批照片 |

**从照片类型抽图的规则**
- 默认只抽在“照片类型”页**人工确认过**的照片（最准）；不勾“只抽人工确认过的”，模型预测的也会抽，标成待复核。
- 抽过的不会重复抽。以后在照片类型页又确认了新照片，再运行一次就只抽新的。
- 一次最多 1000 张。
- 以前抽进来、没带类别的旧图，用「按照片类型补类别」补上（先勾“只统计，不写入”看看能补多少）。

**原图与分拣页的小技巧**
- 每页张数可选 36 / 60 / 100 / 200，能跳页。
- 「选中全部筛选结果」一次选中当前筛选范围的全部图片（最多 1000 张），不用一页页点。

---

## 2. 设好类别

工作台 →“标注系统”→“检测类别”→「添加类别」。

- 类别代码用**小写字母、数字、下划线**，比如 `rust_spot`。Label Studio 里的标签写成 `rust spot`、`Rust-Spot` 也能自动对上。
- **类别只能在末尾追加**，不要删、不要改名、不要调顺序。已有标注和模型都按类别顺序编号，一动就全错位。
- 第一次建子项目时就把已知要识别的类别都加上；以后要加，按第 7 节“加新类别”走。

---

## 3. 连接 Label Studio 并开启自动回收

工作台 →“标注系统”。

1. 第一次用时，点「提交所选图片」会提示一键连接；也可以在工作流里运行「连接 Label Studio」。引擎会按当前类别**自动生成**标注配置。
2. 点「**开启自动回收**」。之后你在 Label Studio 里一提交或修改标注，引擎就自动收进来，不用再手动回收。

标注系统页上方的状态区会显示：任务数、已标注、已回收到引擎、自动回收是否开启，以及配置问题。

> **不要在 Label Studio 里手动建项目或改标注配置。** 手动建的项目通常缺少 “Targets reviewed / No target” 选项，引擎没法确认框画全了，**一张都收不进来**。如果页面提示“标注配置不完整”，点「按现在的类别新建 Label Studio 项目」。

---

## 4. 送图去标注

- **从零画框**：在“原图与分拣”选图 →「提交标注」。
- **让模型先画好框**（已经有模型时，推荐）：工作流节点「送 Label Studio（带模型预框）」。

已经送过的图不会重复送。

---

## 5. 在 Label Studio 里标注

每张图：

1. 点上方的类别标签（如 `crack`），在图上拖出框。**这张图里所有类别的目标都要框**，不能只框一种。
2. 图片下方选一个确认选项（可能要往下滚一点才能看到）：
   - **Targets reviewed**：框都画完了；
   - **No target**：图里一个目标都没有；
   - **Unsure**：拿不准，这张不会进数据集。
3. 点 **Submit**（或按 `Ctrl+Enter`）。

**只有选了 Targets reviewed 或 No target 的图才算已复核，才能进数据集。** 草稿、跳过、Unsure 都不算。

注意：
- 不要画**旋转框**。普通检测不支持，旋转过的框整张图会被排除。
- 想批量确认：任务列表全选 → **Actions** → **Create Annotations From Predictions**。这等于**不看就认可**预填的框，只对你确定没问题的批次用（见第 7 节）。

---

## 6. 打包数据集、训练、上线

**打包**：数据集页 →「回收并打包」。会先回收一次，再把所有已复核的标注打包成新版本（如 `demo-r1`、`demo-r2`…），自动分好训练 / 验证 / 测试。对话框里会写明打包的是哪个子项目，先核对。

**训练**：模型中心 →「训练新模型」。

| 项目 | 建议 |
|---|---|
| 基础模型 | 初版、要快：YOLOv8s；正式版、要准：YOLOv8m |
| 数据集 | 刚打包的最新版本 |
| 训练轮数 | 图少（几百张以内）选 150；效果不再提升会提前停 |
| 批大小 | 自动；报显存不足就选 8 或 4 |
| 图像大小 | 640；目标很小、很细长时选 960 |
| 在哪训练 | 服务器 |

**上线**：训练完会自动评估并设为“最新”（`latest`）。看测试集成绩，满意再点「设为正式使用」（`production`）。

成绩怎么看：
- 每个类别分开看 mAP50。某一类明显低，多半是这一类标注少或标注不一致，先补这一类。
- 用训练过的图评估分数会虚高。看测试集，或拿没参与训练的新照片在“试一试”里看。

---

## 7. 给模型加新类别（以后每次加类别都这样走）

加了新类别以后，**以前的标注没检查过新类别**。直接拿去训练，图里有新目标却没框，模型会被教成“这不是目标”。所以旧标注要先补查新类别才能进数据集。系统会自动把它们挡在数据集外，并提示“需要复核”。

### 第 1 步：加类别

标注系统 →「添加类别」，输入新类别代码。

### 第 2 步：换一个配置完整的 Label Studio 项目

如果页面提示“标注配置不完整”（缺新类别标签或缺确认选项），点「**按现在的类别新建 Label Studio 项目**」。旧项目留在 Label Studio 里不动；新项目自动开启自动回收。之后都在新项目里标。

### 第 3 步：先标一批新类别

先要有一批画了新类别的图，用来训一个初版模型。

- 如果以前已经在别处画过新类别（比如旧 Label Studio 项目里有、但没收进来），点「**送回 Label Studio 复核**」，送哪些选 `rejected`，**带着已有的框**送进新项目。
- 否则从照片类型页抽一批含新类别的照片，正常标注。

送回复核时默认**预选好确认选项**（有框选 Targets reviewed，没框选 No target）：打开看一眼，没问题直接 `Ctrl+Enter`；自己亲手标过的批次可以整批确认。

### 第 4 步：训练初版模型

打包 → 训练（YOLOv8s、150 轮即可）。这一版只用来给旧图预画新类别的框，不用设为正式使用。

### 第 5 步：用初版模型补查旧图

「送回 Label Studio 复核」：
- 送哪些：`stale`（加新类别前已通过的旧标注）
- 给新类别预画框的模型：`latest`
- 勾选「替换还没人标过的任务」

系统用很低的门槛（5%）跑一遍模型，把旧图分成两批，在 Label Studio 里各建一个标签页：

| 标签页 | 怎么处理 |
|---|---|
| 复核·可整批确认（模型没发现新类别） | 全选 → Actions → Create Annotations From Predictions，一次确认完 |
| 复核·要看（模型发现新类别） | 逐张看一眼，框对就 `Ctrl+Enter` |

通常大部分旧图里没有新类别，真正要看的只是一小部分。

### 第 6 步：再打包、再训练

打包出新版本（如 `demo-r2`）→ 用 YOLOv8m、150 轮训练 → 看成绩 → 设为正式使用。

## 8. 注意事项和常见问题

| 现象 | 原因 / 做法 |
|---|---|
| 打包报 “No accepted samples are ready to publish” | 当前子项目没有已复核的标注。先看顶部子项目选对没有；再到标注系统点「立即回收标注」；确认每张图都选了 Targets reviewed / No target |
| 打包报 “Need at least 3 independent site or duplicate groups” | 已复核的图太少（要能分成训练 / 验证 / 测试三份）。多标几张再打包 |
| 回收了但“已回收到引擎”比“已标注”少很多 | 有的图没选确认选项、类别名对不上、或画了旋转框。标注系统页的“需要复核”会列出数量，用「送回 Label Studio 复核」处理 |
| 标注系统提示“需要复核：加新类别前的旧标注” | 正常，按第 7 节第 5 步补查 |
| Label Studio 里看不到 Targets reviewed | 打开的是旧项目或手动建的项目。用标注系统页的「打开 Label Studio ↗」进当前项目 |
| 整批确认（Create Annotations From Predictions）后图都不通过 | 预填里没有确认选项（旧的送图方式）。重新「送回 Label Studio 复核」，勾选「替换还没人标过的任务」；已经整批生成的错误标注要先在 Label Studio 里删掉 |
| 在 Label Studio 里删了标注，引擎里的记录会丢吗 | 不会。没人标的任务不会覆盖引擎里已有的标注记录；所有历史版本都保留 |
| 子项目选错，图抽进了别的子项目 | 抽图只复制，原图不动。到那个子项目里删掉误抽的图即可 |
| 训练报显存不足 | 批大小改 8 或 4，或图像大小改小 |
| 选中图片后提交任务提示超过 1000 张 | 一次最多处理 1000 张：先“清空”，再分批选 |

### 几条原则

1. **类别只追加，不删不改。**
2. **每张图要么框全所有类别并选 Targets reviewed，要么选 No target。** 漏框会把模型教坏。
3. **整批确认等于不看就认可。** 只用于你亲手标过的、或模型确认没有新类别的批次。
4. **Label Studio 项目让引擎来建。** 类别变了就让引擎新建一个，不要手动改配置。
5. **评估看测试集或新照片**，不要只看训练过的图。
