# 中英文切换（国际化 / i18n）

界面照常用中文写。用户在顶部导航点「中 · EN」切到英文后，`lota/static/i18n.js` 会把页面上的中文实时换成英文。没有顶部导航的页面（手机页、旧页面）在左下角有一个浮动的切换按钮。选择保存在浏览器里（localStorage 的 `lota-lang`）；第一次打开时按浏览器语言决定，中文浏览器默认中文。

## 怎么翻的

1. **整句**精确匹配（`static/i18n/en.json` 的 `exact`）。
2. **去掉前后的图标或符号**后再查整句，如「🗃️ 其他/无关」。
3. **带变量的模板**（`patterns`），如 `已选 {0} 张` → `Selected {0}`。变量里的中文（类型名、类别名）也会接着翻。
4. 按标点**拆成短语**，逐段翻。用于运行时拼起来的句子。
5. 最后一招：已知**词组替换**。

页面上新出现的内容（弹窗、提示、接口返回的文字）由 MutationObserver 自动翻。也会翻 `title` / `placeholder` / `aria-label` / `alt` 属性、网页标题、浏览器自带的 alert / confirm / prompt，以及画在图片上的标签（`UI.drawBoxes`）。

**不翻**：输入框里的内容、`<textarea>`、`<code>`，以及加了 `data-i18n-skip` 或 `class="no-i18n"` 的元素。

## 改了界面文字之后怎么更新英文

在本机运行第 1 步，后面三步在装了 Ollama 的服务器上运行：

```bash
# ① 本机：提取所有中文（新文字会追加进来）
python scripts/i18n_extract.py              # → i18n/strings.json
# 把 i18n/strings.json 和 scripts/ 传到服务器的引擎目录下面

# ② 服务器：用本机 Ollama（qwen3.5:9b）翻译新增的文字，可以断点续跑
#    每一批之前会查引擎有没有任务在跑，有就等，不和训练抢显卡
LOTA_API_TOKEN=... python3 scripts/i18n_translate.py   # → i18n/en.auto.json；没译成的在 en.failed.json

# ③ 服务器：合并成界面用的字典
python3 scripts/i18n_build.py               # → app/lota/static/i18n/en.json

# ④ 所有 html 里 i18n.js?v=N 的 N 加 1，让浏览器重新下载字典
```

- **手工译文**写在 `i18n/en.manual.json`，优先级最高：机器翻得不好的、项目名称这类，放这里改。
- **术语表**在 `i18n/glossary.json`，翻译时强制使用统一叫法（如 子项目 = Project、正式使用 = Production）。

## 文件

| 文件 | 作用 |
|---|---|
| `lota/static/i18n.js` | 运行时翻译、切换按钮（所有页面 `<head>` 里第一个加载） |
| `lota/static/i18n/en.json` | 界面用的字典（生成的，不要手改） |
| `i18n/strings.json` | 提取出来的中文和它们出自哪个文件 |
| `i18n/en.auto.json` | 机器翻译结果 |
| `i18n/en.manual.json` | 手工译文（优先） |
| `i18n/glossary.json` | 术语表 |
| `scripts/i18n_extract.py` / `i18n_translate.py` / `i18n_build.py` | 提取 / 翻译 / 合并 |

## 还没覆盖的

- **用户自己输入的内容**：子项目名称、类别中文名、备注、质检规则里写的提示语等。这些是数据，按原样显示。官方库和演示子项目的名称已经在 `en.manual.json` 里配好了英文。
- **接口和 MCP 返回给 Agent 的文字**仍是中文。以后可以按 `Accept-Language` 返回英文。
